波形窗口：把终端的提示符换成一帧串口波形

Windows Terminal 用「窗口 + 提示符」表达命令行，按微软规范在 48 格网格上画、外圆角 2px、形状尽量少，16–24px 仍可辨。这里只迁移它的轮廓逻辑：蓝色标题条 + 深色正文区，正文里的提示符换成一个 UART 帧（起始位拉低、数据位、停止位拉高）。form 来自内容：日志区就是这个应用的主角，波形是串口独有、终端没有的东西。
