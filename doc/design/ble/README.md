## 布局

```
┌ 菜单栏 34px ───────────────────────────────────────────────────────────┐
├ 连接页签 36px ─────────────────────────────────────────────────────────┤
│ 左栏 300px     │ 数据日志 + 发送框                       │ 工具面板 352px │
│ 扫描 / 连接    │                                         │ 快捷 / 批量 /  │
│ GATT 钉选     │                                         │ 应答 / 历史 /  │
│ MTU / 写入方式 │                                         │ 校验 | 脚本    │
├────────────────┴─────────────────────────────────────────┴────────────────┤
│ 状态栏：设备 CONNECTED|CLOSED, MTU, 写入方式 │ Notify │ Write │ RX │ TX │
└───────────────────────────────────────────────────────────────────────────┘
```

外壳沿用多协议 A 方案：菜单栏、连接页签、状态栏。左栏可展开 GATT，用来把 Notify 和 Write 钉到这条连接上；钉完后主区就是原来的日志和发送。

## 钉选规则

- 同时只能钉一只 Notify、一只 Write。只读特征不可钉。
- 未钉 Write 时，发送框、快捷指令、批量都拦截，提示「还没有钉住 Write 特征」。
- 未钉 Notify 时，发出的数据仍可走 Write，回包不进日志。
- 换钉之后，发送框、快捷指令、批量、自动应答都改走新特征。
- 状态栏写明设备和当前两只被钉住的 UUID。

## 模拟设备

- 适配器就绪。扫描得到 Sensor-A4（可连）和 EnvTag-B2（拒绝连接）。
- Sensor-A4 的 GATT：Device Information（只读）、Battery（读 + Notify）、透传 `FFF0`（`FFF1` Notify，`FFF2` Write）。
- 透传帧与 [`../design.md`](../design.md) 第 5 节相同：`A5 01 00 00 01 07` 读温湿度，通知 `A5 5A 03 …`。
