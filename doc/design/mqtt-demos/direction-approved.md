# MQTT 调试方向确认

## 三版初稿

| 方向 | 逻辑 | 文件 | 截图 |
|------|------|------|------|
| 会话继承 | 左栏连接 / 订阅 / 发布，中间日志 + 发布框 | `inherit.html` | `inherit.png` |
| 主题树 | 左侧主题树 + 分支报文 + Payload 检查 | `tree.html` | `tree.png` |
| 报文流 | 报文表 + 过滤条 + 底部发布坞 | `stream.html` | `stream.png` |

## 最终选择

用户于 2026-10-21 确认：

> 使用inherit，发送的主题可以提前录入好，选择后填入发送区的主题输入框

选定 **会话继承**。后续改稿以 `inherit.html` 为准。

选定后的调整：左栏「发布默认值」改为「发布主题」列表，点「填入」只写入发送区 Topic，不立刻发布。QoS / Retain 仍在发送区顶栏。

当前阶段只冻结 MQTT 调试区设计，不改 `option-a/`，不进入 Flutter。
