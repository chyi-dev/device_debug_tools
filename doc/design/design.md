# 串口调试台 · 设计说明

最终设计稿：[`serial-console.html`](serial-console.html)（双击打开，模拟数据可交互）。截图：[`serial-console-light.png`](serial-console-light.png)、[`serial-console-dark.png`](serial-console-dark.png)。方向来源见 [`direction-approved.md`](direction-approved.md)。

布局与功能分区参照野人家园串口调试助手 V5.15。产品名为「设备调试工具」，界面里不出现 UartAssist 名称或 logo。

## 1. 布局

```
┌ 菜单栏 34px ───────────────────────────────────────────────────────────┐
│ 设备调试工具  文件  设置  工具  帮助                    精简模式  工具面板 │
├──────────────┬───────────────────────────────────────┬─────────────────┤
│ 左栏 272px    │ 数据日志（标题行 36px + 日志区，自适应）    │ 工具面板 352px   │
│ 串口设置      │                                       │ 快捷指令/批量发送 │
│ 接收设置      ├───────────────────────────────────────┤ /自动应答/历史发送│
│ 发送设置      │ 发送框 104px + 发送/清除按钮列 120px      │ /校验计算/脚本   │
├──────────────┴───────────────────────────────────────┴─────────────────┤
│ 状态栏 30px：● COM3 OPENED, 115200, N, 8, 1, NONE │ RX │ TX │ 复位计数 │ … │
└────────────────────────────────────────────────────────────────────────┘
```

- 桌面端隐藏系统标题栏，菜单栏兼作窗口标题栏：最左加 16px 应用图标，最右接最小化 / 最大化 / 关闭按钮；产品名与菜单之后的空白可拖拽移动窗口、双击最大化。
- 主体外边距与栏间距均为 8px，最小窗口宽度 1180px。
- 左栏三个分组在 1440×900 下恰好放下，不出现滚动；更矮的窗口允许左栏纵向滚动，中间和右栏各自滚动。
- 精简模式收起左栏，工具面板可单独隐藏；两者同时隐藏时只剩数据日志与发送框。
- 中间数据日志占满剩余高度，是界面的主角。

## 3. 组件

- **分组框**：`panel` 底、`line` 边框，标题 12px `muted`。接收、发送分组的 ASCII/HEX 单选放在标题行右侧。
- **打开/关闭按钮**：整行宽，左侧状态灯（关闭红、打开绿）。关闭状态是主按钮样式，打开后变为普通按钮；串口打开时串口号不可改，其余参数改动即时生效。
- **引脚灯**：DCD、DSR、CTS、RI 一行，8px 圆点，有效为 `on`。
- **数据日志**：标题行含记录数与搜索框；日志区等宽字体、可选自动换行。
- **发送框**：多行等宽输入；右侧「发送」主按钮（循环中变为红色「停止循环」）和「清除」；底部一行实时显示「实发 N 字节：…」或格式错误。
- **工具面板列表项**：左侧主操作（发送按钮 / 开关 / 时间按钮），中间名称 + 等宽数据，右侧次要操作（快捷键标识、编辑、删除），悬停整行变 `hover`。
- **快捷指令文件夹行**：展开箭头 + 名称（600 字重）+ 条数，右侧「新增 / 重命名 / 删除」；文件夹内指令行左缩进 16px。
- **对话框**：统一用于新增、编辑、删除确认和说明；校验失败在对话框底部红字提示，不关闭对话框。点遮罩或 Esc 关闭。
- **提示条**：底部居中，1.9 秒自动消失；错误为红底。持续性状态写在状态栏最右侧。

## 4. 交互规则

### 连接

- 状态栏格式固定为 `端口 OPENED|CLOSED, 波特率, 校验, 数据位, 停止位, 流控`。
- 波特率可输入非标准值，必须为正整数。校验位 NONE/ODD/EVEN/MARK/SPACE，数据位 5–8，停止位 1/1.5/2，流控 NONE/RTS/CTS/DTR/DSR/XON/XOFF。
- 串口关闭时，发送、快捷指令、批量、自动应答都不执行，并提示「串口未打开，发送已拦截」。

### 接收

- **日志模式**（默认）：每条记录两行——`[YYYY-MM-DD HH:mm:ss.SSS]# RECV HEX>` 和数据本身；发送记作 `SEND`，系统消息直接跟在 `#` 后。
- **非日志模式**：只显示接收数据流，不带时间，也不显示发送。
- ASCII/HEX 切换会重绘全部已接收内容；ASCII 中不可打印字节显示为 `.`。
- 接收数据不显示：仍计数、仍触发应答，只是不渲染。
- 接收保存到文件：勾选开始缓存，取消勾选时写出 `.log`；状态栏显示保存进度。
- 分包超时（默认 20ms）：同一超时窗口内到达的字节合并为一条记录。

### 发送

- HEX 模式要求成对十六进制字符；ASCII 模式下「自动解析转义符」支持 `\r \n \t \0 \\ \xHH \x[HH HH …]`。
- AT 指令自动回车：ASCII 内容以 `AT` 开头时补 `\r\n`（已以 `\r\n` 结尾则不重复）。
- 附加位追加在数据末尾：SUM8、XOR/BCC、LRC、CRC8、CRC16（MODBUS，低字节在前）、CRC32（IEEE，大端）。
- 切换发送格式时转换发送框内容。
- 文件数据源：读入文件字节，发送框只读显示前 256 字节的 HEX；取消勾选恢复手动输入。
- 循环周期至少 10ms；Esc 或再次点按钮停止。
- **历史发送只记录用「发送」按钮（或 Ctrl+Enter）发出的数据**；快捷指令、批量、自动应答发出的数据不进历史。

### 工具面板

| 页签 | 规则 |
|---|---|
| 快捷指令 | 点「发送」立即发出；可绑定 F1–F8，一个键在所有文件夹中只属于一条指令。支持单层文件夹：根目录可混放指令和文件夹，文件夹内只放指令；点文件夹行展开 / 收起，行内可新增、重命名、删除（连同其中指令，确认框写明条数）；编辑指令时可选所属文件夹，换文件夹后追加到目标末尾；旧的平铺数据读入后留在根目录 |
| 批量发送 | 每条指令的延时为发送本条前的等待，第一条立即发送；可设重复轮数、失败即停；运行中高亮当前行并显示进度 |
| 自动应答 | 语法分模板和正则，格式分 HEX 和 ASCII（ASCII 可忽略大小写）。模板的匹配方式为前缀 / 整帧 / 包含 / 结尾；HEX 里 `??` 匹配任意一字节、`*` 匹配任意长度，ASCII 里对应 `?`、`*`（`\?` `\*` `\r` `\n` `\xHH` 为字面量）。正则不选匹配方式，锚点写在表达式里；HEX 正则对空格分隔的大写 HEX 串匹配，ASCII 正则对原始字节逐字匹配。应答为 HEX，可写 `$1`、`$2` 填入通配符或括号分组捕获到的字节；模板保存时检查引用不超过通配符个数，正则引用不存在时跳过该条并写系统日志。旧规则按「模板 + HEX」读入。按列表顺序匹配，命中后按应答列表依次发送，延时从上一条发出后计算；显示命中次数。新增 / 编辑应答规则对话框默认与其他编辑框同宽，课表收起；点标题栏右侧「教程」按钮后对话框加宽，左侧仍是原表单，右侧是课表（再点收起，表单内容保留）：模板四课、正则三课。点一课展开说明、字节格（被抓进 `$n` 的用搜索高亮色）和将发出的 HEX。「填入编辑器」只写入左边表单，点保存才进规则列表。默认展开「?? 抓一字节，* 抓一段」 |
| 历史发送 | 点时间按钮重发，「填入」放回发送框，可删除或清空 |
| 校验计算 | 同时列出六种算法结果；「追加」把原数据和校验值一起填回发送框 |
| 脚本 | Lua 脚本。页签放在最右，用竖线与其他页签隔开，表示它会改动中间列。右栏只有列表（开关 + 名称 + 钩子标识 + 输出次数）和说明；点一行选中，中间列在数据日志与发送框之间停靠 312px 高的脚本区：标题行为脚本名、钩子、启用状态，右侧「运行」「收起」；下方左侧是带行号的代码编辑器（输入即保存，Tab 缩进两格），右侧 380px 是完整运行日志。数据日志与发送框保持可见；切到其他页签或点「收起」时脚本区收回。钩子由代码里定义的函数决定：`on_receive(frame)` 在收到数据后运行；`before_send(frame)` 拦截每一帧发送（发送按钮、快捷指令、批量、自动应答都经过），返回处理后的帧再发出，返回 `nil` 则不发；多个 `before_send` 按列表顺序串联。开关只控制自动运行；「运行」随时手动试一次，`before_send` 拿发送框内容试算、不真正发出。运行日志每条为时间 + 脚本名 + 一行输出，错误为红字。列表上方是「我的脚本 / 教程」分段切换；「教程」把列表换成六课（脚本什么时候运行、把一帧打印出来、认帧头取数值、发送前补校验、拦截不想发的帧、Modbus 补 CRC16），点一课展开说明、代码与样例帧，「用这课新建脚本」用该课代码新建（默认停用）并切回我的脚本、打开编辑区，「样例试跑」把样例帧交给这段代码，输出写进运行日志、不发数据。课的代码只用脚本引擎已有的接口 |

### 配置导入导出

文件菜单「导出配置… / 导入配置…」只打包四类用户内容：快捷指令、自动应答、批量发送、脚本。串口参数、收发选项、历史发送和窗口布局不进文件。

- 文件为 JSON 对象：`{ "kind": "device-debug-config", "version": 1, "quick": [...], "rules": [...], "batch": [...], "scripts": [...] }`。四个键都可缺省，各列表字段与本地存储一致；默认文件名 `device-debug-config.json`。
- 导出对话框是四行清单：勾选框 + 类别名 + 当前条数，默认全勾；只写入勾选的键，一个都不勾时对话框内红字「至少勾选一类」。
- 导入先选文件，再弹同样的四行清单：文件里有的类别默认勾选，行尾写「文件 N 条，替换当前 M 条」；文件里没有的类别置灰禁用，写「文件里没有，保持当前 M 条」。勾选的类别整表替换、无法撤销，不勾的保持现状；空列表照样替换为空。
- 旧的单列表文件（以前导出的快捷指令或应答规则 JSON 数组）也能导入：按首项形状认出类别（`steps` 为批量、`code` 为脚本、`pattern`/`replies` 为应答、其余为快捷指令），文件名旁标「旧格式 · 单类列表」，只开放那一行。认不出、不是本工具的文件或不是 JSON 时给出提示，不打开对话框。
- 替换时：快捷键重复只保留第一条；应答命中次数归零；脚本启用状态随文件走，勾选脚本且文件里有启用的脚本时，清单下方用强调色写「其中 N 个脚本是启用状态，导入后立即参与自动运行」；批量发送正在运行且勾选了批量时，写明「导入会先停止它」并在替换前停止。
- 导入完成提示每类导入后的条数，例如「已导入 快捷指令 5 条，脚本 3 个」。

## 5. 设计稿里的模拟协议

设计稿用一块温湿度传感器演示，Flutter 实现时由真实串口替换：

| 方向 | 帧 | 含义 |
|---|---|---|
| TX | `A5 01 00 00 01 07` | 读取温湿度 |
| TX | `A5 02 00 00 02 08` | 读取设备信息 |
| TX | `A5 10 01 00 11` / `A5 10 00 00 10` | 启动 / 停止采集（每 3 秒上报） |
| RX | `A5 5A 03 TT TT HH HH SS` | 温度 ×10、湿度 ×10（大端），`SS` 为前 7 字节 SUM8 |
| RX | `A5 5A 82 …ASCII… SS` | 设备信息 |
| RX | `A5 81 00 00 81` | 上线确认 |

DTR 回环到 DSR、RTS 回环到 CTS，打开即有 DCD。

## 6. 落地到 Flutter

- 目录：`lib/features/serial/`（`page/`、`cubit/`、`widget/`、`repository/`、`model/`），页面级 Cubit，不使用 Bloc 事件模式。
- 颜色：上表 token 加入 `AppColors`（白底 / 黑底两套），主题切换走 `AppCubit`，与设置菜单「白底经典 / 黑底经典」对应。
- 尺寸：间距用 `AppSpacing`（4/8/12/16），圆角用 `radiusSm`；日志与发送框用 `AppTextStyles.mono`，日志字号按本稿取 14px。
- 文案：所有界面文字走 slang（`lib/i18n/*.i18n.json`），状态栏的 `OPENED/CLOSED` 与日志提示符 `RECV/SEND` 属于协议式标记，保持英文。
- 窗口小于 1180px 宽时默认进入精简模式，并可隐藏工具面板。
- 脚本：设计稿只模拟两个预置脚本的效果，不执行 Lua。Flutter 落地需要另选 Lua 运行时并评估依赖；`before_send` 挂在仓库写串口之前，`on_receive` 挂在分包合并之后。钩子名 `on_receive` / `before_send` 属于脚本接口，不翻译。
