# MCP 三套初稿

外壳沿用白底经典工作台。三版只换助手出现的位置。配色相同。

| 文件 | 方向 |
|------|------|
| [thumbs.html](thumbs.html) | 六格缩略图。1、3、4 做成了完整版 |
| [dir-1.html](dir-1.html) | 设置里的抽屉，三档开关 |
| [dir-2.html](dir-2.html) | 页签逐条纳入，发出前先在横栏里看见字节 |
| [dir-3.html](dir-3.html) | 选定。设置在顶部菜单弹窗，右栏 MCP 页是日志 |

双击 HTML 即可点。选定记录在 [direction-approved.md](direction-approved.md)。此阶段不改 `lib/`。

方案 3 可点的路径：设置菜单打开 MCP 弹窗，用勾选和启用策略控制授权；在脚本或自动应答页点「助手写入」，询问时弹出启用确认；右栏 MCP 日志记下调整和导入。

说明见 [spec.md](spec.md) 与 [directions.md](directions.md)。
