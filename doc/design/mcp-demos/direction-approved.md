用户于同日改了设置的位置和授权内容：

> MCP设置应该放在顶部的选项中，点击弹出设置弹窗：内部相关选项使用checkbox控制开关；
> 其中的授权卡片中为：发送数据，读取数据，自动应答，实现脚本：启用或者禁用；自动应答启用策略：（下拉选择：默认启用，默认禁用，询问）；脚本启用策略：（下拉选择：默认启用，默认禁用，询问）
> 原有连接和草稿设置移除；
> 脚本和自动应答：ai通过mcp写完脚本后导入应用中，根据设置是否启用脚本，需要询问则弹窗（标题，脚本内容，启用和取消按钮）；
> mcp日志主要记录通过mcp调整了什么内容，执行了什么动作。

## 这一版怎么摆

- 顶部「设置」里点 MCP，弹出设置对话框。开关都是勾选。授权卡片含：发送数据、读取数据、自动应答、实现脚本，以及自动应答启用策略、脚本启用策略（默认启用 / 默认禁用 / 询问）。
- 不再放连接范围，也不再放草稿。脚本和自动应答导入后出现在原来的「脚本」「自动应答」页。
- 策略为询问时，弹出对话框：标题、内容、启用和取消。取消则导入但未启用。
- 右栏 MCP 页只留日志，样式仍是串口数据日志。每行记一次调整或一次动作，例如允许发送数据、导入脚本并写明是否启用。

未选的抽屉方案和批准条方案留在 [dir-1.html](dir-1.html)、[dir-2.html](dir-2.html)。此阶段不改 `lib/`。
