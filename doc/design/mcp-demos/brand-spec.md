# 品牌资产

这次设计的是本仓库自己的「设备调试工具」，不是第三方战役页。

## 已使用的真实界面

- 外壳与 token 取自 [06-designer-console-evolved.html](../../shell-redesign/06-designer-console-evolved.html)，也就是 2026-11-05 选定、后续在其上改动的 F 稿。
- 色值以该文件 `:root` 为准，与 `lib/app/theme/app_colors.dart` 的白底经典一致：窗口 `#e6e9ed`，面板 `#f4f6f8`，强调 `#1666bc`，开 `#1f9d55`，关 `#c8392f`。
- 没有另做 logo。窗口左上角沿用 F 稿那个 16px 蓝块图标，它是界面的一部分，不是新标志。

## Cursor

界面里会写出客户端名字 Cursor，因为助手是从 Cursor 连到已打开的工作台。本轮没有嵌入 Cursor 的官方标志，避免手画一个假标。名字只作为一行状态文字。

## 没有使用的东西

- 不放 MQTT、蓝牙联盟或芯片厂商的 logo。
- 不编一台新设备的产品图。主角是工作台里已经有的那一帧字节。
