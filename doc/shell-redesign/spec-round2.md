# 第二轮方向 · 修正「不像调试工具」

## 用户原话（2026-11-05）

> 这三个版本都不行，重新设计  
> 不像调试工具；介于两者之间;你看着办

## 判定

第一轮失败主因是气质偏产品站 / 终端生活方式 / 设计馆仪器，而不是**联调工程师每天打开的收发台**。第二轮三版必须一眼能认成调试工具：分组框、等宽日志、连接态、密集表单、可拖分割；可以离开旧色板，但不能做成 SaaS 营销壳。

「介于两者之间」= 保留菜单 → 连接页签 → 设置 / 日志 / 发送 / 工具 / 状态栏的工作记忆；允许调左右位置、工具条形态、密度；不要推倒成监控墙或工作区 IDE。

## 第二轮锚点

| 逻辑 | 锚点 | 调试工具化约束 |
|------|------|----------------|
| 🎲 轮盘 | 秒 52 → `52%20+1=13` → Glassmorphism Bento | **降级**：去掉毛玻璃/大圆角胶囊；只保留「模块化分组」密度，做成浅色 Windows 调试台 |
| 🏆 参照 | **Serial Studio**（真实串口/遥测桌面工具：顶栏 + 中 Console + 右侧 Device Setup） | 设置改到**右侧**；日志仍是等宽流，不是卡片 feed |
| 🧠 设计师 | **现网串口台进化**（野人家园式工作记忆 + 更干净的分割与层级） | 左设置 / 中日志发送 / 右工具不变；强化可拖与细节，色板可微调但仍是仪器白/灰 |
