# 设备调试工具 · 外壳布局重设计 Spec

> 本轮产物只存在于 `doc/shell-redesign/`，不修改 `doc/design/`。
> 输出：三份 1440×900 可交互 HTML 方向稿 + 截图；选定前不改 Flutter。

## 1. 产品是什么

「设备调试工具」是 Windows / macOS / Linux 桌面端多协议调试台。用户整天盯着字节流：打开串口 / BLE / MQTT / TCP·UDP，看接收日志，敲发送，跑快捷指令、批量、自动应答和 Lua 脚本。当前四套调试台共用固定三栏骨架（左 272 / 中自适应 / 右 352，发送框高 104，脚本坞高 312），视觉是白底/黑底经典仪器风。本轮允许离开旧视觉语言，但能力位不能丢。

## 2. 受众与场景

- **受众**：嵌入式、物联网、现场联调工程师；长时间单屏工作，键盘与鼠标并用。
- **场景**：笔记本或外接显示器，窗口常在 1280–1920 宽；需要一边看日志一边改设置或点工具。
- **情感基调**：冷静、可靠、可长时间盯着；像专业仪器，不像营销落地页。气质关键词：**精密、可读、可调、克制**。
- **潜在期待**：分区能拖；日志永远是主角；密度够用但不花哨；四个协议共用同一外壳手感。

## 3. 核心信息与内容板块（三版同内容）

主画面演示**串口工作台**（能力最全）。顶栏连接页签同时出现：`COM3 · 串口`、`蓝牙 · 灯控`、`MQTT · broker`、`TCP · 板卡`，证明外壳通用。不画全四个协议的设置表单。

必须出现的功能位：

1. **菜单栏**：设备调试工具 · 文件 / 设置 / 工具 / 帮助 · 精简模式 · 工具面板 · 窗控
2. **连接页签**：多协议页签 +「＋ 新增」
3. **左设置**：串口设置（端口/波特率/打开）、接收设置、发送设置
4. **数据日志**（主角）：标题行（记录数、搜索）、等宽收发流
5. **发送框**：多行输入 + 发送 / 清除
6. **右工具**：快捷指令 / 批量发送 / 自动应答 / 历史 / 校验 / 脚本
7. **脚本坞**（可开关）：中间列日志与发送之间；左编辑器 + 右运行日志
8. **状态栏**：`COM3 OPENED, 115200, N, 8, 1, NONE` · RX/TX · 复位

文案用产品已有中文，禁止 Lorem /「标题文字」占位。

## 4. 输出格式与尺寸

- **形态**：可双击打开的单文件交互原型（桌面工作台 mock），不是落地页，不是 PPT。
- **画布**：固定 **1440 × 900** 逻辑像素；页面居中 letterbox。
- **截图**：同尺寸一张静帧。
- **目录**：
  - `spec.md`（本文件）
  - `01-roulette-terminal-core.html` + `.png`
  - `02-reference-warp.html` + `.png`
  - `03-designer-rams.html` + `.png`

## 5. 可拖分区（三版硬要求）

| 分割 | 方向 | 默认（参考现网） | 行为 |
|------|------|------------------|------|
| 左设置 \| 中间 | 横向 | 左 ≈272 | 拖宽；双击还原；拖到最小收起（精简） |
| 中间 \| 右工具 | 横向 | 右 ≈352 | 同上；拖到最小隐藏工具面板 |
| 日志 \| 脚本坞 \| 发送 | 纵向 | 脚本 312 / 发送 104 | 脚本可关；双击还原 |
| 脚本编辑 \| 运行日志 | 横向 | 右日志 ≈380 | 双击还原 |

分割条需可见、可抓；拖拽时禁止面板被压成不可读细条——到阈值即折叠。

## 6. 已知约束与禁忌

- 高密度：正文 ≥14px，标签/注释 ≥12px，正文对比度 ≥4.5:1。
- 反 slop：禁止紫渐变满版、emoji 图标、圆角卡片+左色条、GitHub-dark+#0D1117+霓虹青紫光、装饰性图标墙。
- 三版**布局骨架必须互异**（导航/构图/内容区至少一项结构性不同），不许只换皮。
- 日志区是第一眼锚点；空白靠构图，不靠编造 stats 填满。
- 本轮不改 Dart、不碰 `doc/design/`。

## 7. 图片需求

工具型界面，**不需要外部配图**。界面本身用真实中文文案 + 模拟日志字节即可。禁止 SVG 手绘装饰插画。

## 8. 视觉母题（form 从内容长出来）

调试台的内容母题是**「帧」**：时间戳、方向（RECV/SEND）、HEX/ASCII 载荷。设计应从「一帧一行/一块」长出结构——分割线像示波器栅格、等宽字像探针读数、强调色只标连接态与可执行动作。不要做成 SaaS 营销站。

## 9. 三套逻辑锚点（开写前锁定）

| 逻辑 | 锚点 | 骨架差异承诺 |
|------|------|--------------|
| 🎲 轮盘 | 秒 35 → `35%20+1=16` → **Terminal-Core Soft-Futurism** | 经典三栏 + 面板内 bento 卡片；炭黑底、暖白字、克制冷青 accent；等宽字主导日志 |
| 🏆 现实参照 | **Warp**（块状终端、暖近黑、羊皮纸字色） | 日志改为「块列表」；左侧更窄的会话轨 + 设置叠在中上；暖灰表面 |
| 🧠 设计师 | **Dieter Rams / Braun 工业仪器** 方法 | 浅冷灰工作台；工具区改为**底部可调高横条**（非右侧栏）；橙 accent 只给主操作 |

## 10. 顾问式重述

用户要的不是再画一版野人家园仿制，而是把每天要盯的调试外壳重新立住：整体布局、细节、以及区域之间能拖宽度/高度。能力不能缩水——菜单、页签、左设置、日志、发送、工具、脚本坞、状态栏都要在。视觉可以离开旧 token，但不能滑进 AI 默认的紫渐变暗色 SaaS。四套协议以后共用同一手感，所以外壳要比单页串口更「系统」。基于这个理解，直接做 3 个不同方向的真实版本给人看。
