# 同一块工作台，接下来加上蓝牙和 MQTT

> 摘要：调试设备时通信方式不止一种。以前串口、蓝牙、MQTT 要打开不同工具来回切，后续在这一块工作台里点「＋ 新增」即可同时开着，每条连接各自收发。

调设备很少只走一种通路。USB 转串口、BLE 透传、连上 Broker 收遥测，常常同时出现在同一张工位上。以前要开几个软件，窗口切来切去：这一帧刚发出去，目光已经落到另一块日志上；快捷指令、应答规则和脚本也跟着散在各处。

接下来把蓝牙 BLE 和 MQTT 收进同一块工作台。点「＋ 新增」，选串口、蓝牙 BLE 或 MQTT，顶部多一条连接。常用操作仍在原来的位置：中间看日志、底下发一帧，右侧放已经试通过的指令。一个工具全部搞定。

---

## 蓝牙：先钉住通道，再按原来的手感收发

左栏先扫设备，可按名称或地址过滤，再连接。连上之后展开 GATT，把一只 Notify 和一只 Write 钉到这条连接上。同时只钉各一只，再钉另一只就换掉当前的；只读特征不能钉。

钉完之后，中间仍是数据日志和发送框。写入方式（With / Without Response）、MTU、分片字节留在左栏。几条硬约定：

- 没钉 Write：发送框、快捷指令、批量都拦住，提示「还没有钉住 Write 特征」。
- 没钉 Notify：发出去的数据仍可走 Write，回包不进日志。
- 换钉之后，发送框和右侧工具都改走新特征。

右侧有快捷指令、批量发送、自动应答、历史发送和脚本。蓝牙页没有校验计算。未连接时发送会拦住。

---

## MQTT：订阅列表和发布主题先备好，再发 Payload

左栏填 Broker 和端口，点连接。展开后是三块设置：

- **会话**：3.1.1 或 5.0、Client ID、用户名、密码、Keep Alive、Clean Start、断线自动重连。选 5.0 时还可填 Session Expiry。
- **TLS**：开关、CA 证书、客户端证书、私钥。
- **遗嘱**：Topic、Payload、QoS、Retain。

订阅列表支持 `+` 和 `#`。发布主题先存成列表，点「填入」只写入发送区的 Topic，不立刻发出去。QoS 和 Retain 在发送区顶栏，确认后再发布。

右侧快捷指令可继承当前 Topic，也可单独覆盖 Topic、QoS、Retain。未连接时订阅和发布都会拦住。这一页不带批量、自动应答和脚本。

---

## 原有串口能力继续保留

串口页保持现有能力：端口参数、收发、附加位、快捷指令、批量、自动应答、校验和 Lua 脚本都还在。几条连接可以同时开着，日志和设置各记各的。切页签只是换当前这条通路，不会把另一条的工作区带走。
